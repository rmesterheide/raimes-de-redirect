# raimes.de → raimes.ai

Tiny GitHub Pages site that redirects every request for raimes.de (and www.raimes.de) to https://raimes.ai,
keeping the path. `index.html` and `404.html` are identical so any URL redirects.

DNS for raimes.de points at the GitHub Pages IPs; the custom domain is set on this repo's Pages settings.
The blog itself lives in rmesterheide/raimes.de.
